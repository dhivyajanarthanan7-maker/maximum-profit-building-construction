# Maximum Profit – Building Construction

## Project Overview
This project solves a building-construction profit optimization problem. Given a time limit, it determines the possible combinations of Theatres, Pubs, and Commercial Parks that maximize total earnings.

## Features
- Calculates maximum possible earnings for a given time limit.
- Considers different combinations of building types.
- Displays all building plans that achieve the maximum earnings.
- Accepts different time limits for testing.
- Uses Python to implement the profit calculation logic.

## Technologies Used
- Python
- Recursion
- Algorithmic problem-solving

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

```bash
python max_profit.py
```

5. Enter the required time limit when prompted, if the program requests input.
